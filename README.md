# DesignerHTML

A curated collection of production-grade, highly aesthetic single-page marketing website templates built with vanilla HTML, modern CSS (fluid typography, design tokens, clamp, micro-interactions), and vanilla JS / GSAP scroll animations.

---

## ⚡ Key Technical Features

- **Single Self-Contained Files**: Each `.html` file is self-contained with inline scoped CSS and vanilla JavaScript.
- **Fluid & Responsive Typography**: Scaled using modern CSS `clamp()`, flexible CSS variable tokens, and mobile-first layouts without horizontal overflow.
- **Aesthetic Excellence**: Dark modes, curated HSL palettes, smooth micro-interactions, and accessible semantic markup.
- **Motion Accessibility**: Built-in support for `prefers-reduced-motion` to keep animations graceful and accessible.
